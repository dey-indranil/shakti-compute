# Vision

Shakti Compute is an open-source, vendor-neutral compute stack for writing high-performance kernels once and running them across hardware vendors.

The long-term direction is a CUDA-familiar programming model, a portable runtime, compiler infrastructure, and a small library of practical kernels for AI and scientific computing.

v0.1 is intentionally smaller: a CPU-only runtime seed that establishes the public API shape and keeps the project easy to build.
